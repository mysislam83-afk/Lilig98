# Random Password Generator - Генератор случайных паролей
## Описание

Random Password Generator - это графическое приложение для генерации надёжных случайных паролей с возможностью настройки параметров, оценкой сложности и сохранением истории.

### Возможности
- 🔧 Настройка длины пароля (4-32 символа)
- ✅ Выбор типов символов (буквы, цифры, спецсимволы)
- 🎲 Генерация случайных паролей
- 📋 Копирование в буфер обмена
- 💪 Оценка надёжности пароля
- 📜 История сгенерированных паролей
- 💾 Сохранение истории в JSON
- 📊 Статистика использования
